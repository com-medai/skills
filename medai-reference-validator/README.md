Validate and audit the references/citations in a research manuscript. Use this skill whenever
the user provides a paper, thesis, manuscript, or reference list (.docx, .pdf, .txt, .md, .tex)
and wants their citations checked, verified, or audited — e.g. "check my references", "validate
my citations", "do my DOIs exist", "does this bibliography match the sources", "audit my
reference list", "are my citations real", or worries about fake/AI-hallucinated citations. The
skill verifies each DOI, compares every bibliographic field (authors + order, year, title,
journal, volume, issue, pages) against the authoritative online record, scores how relevant each
citation is to where it is cited, flags retractions/preprints/hygiene issues, and produces a
Word report plus an Excel workbook. Trigger it even if the user only implies reference checking.
